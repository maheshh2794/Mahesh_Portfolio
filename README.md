# Mahesh Babu Gunda — Portfolio

## Preview locally
Open `index.html` in your browser.

## Publish for free using GitHub Pages
1. Create a new public repository on GitHub (for example, `mahesh-portfolio`).
2. Upload `index.html`, `resume.pdf`, and this README.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The public URL will appear in Settings → Pages.

Alternatively, import the folder/repository into Vercel or Netlify and deploy.

## Before publishing
- Check that the contact details are correct and that you want them public.
- Replace the generic GitHub profile link with your actual profile URL.
- Add real GitHub repository and live demo links to project cards when available.
- The content and spelling of skills/projects can be edited directly in `index.html`.
